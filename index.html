🔍 What Is WebGLRipper?

WebGLRipper is a browser extension for Chrome and Firefox that looks at the 3D content your browser is already drawing on screen and lets you save a copy of it. Instead of digging through browser developer tools or hunting for hidden file paths, you open the extension, see a live 3D preview of everything the page has loaded, and click the object you want.

Once you pick an object, WebGLRipper packages its geometry and its textures together and hands you a standard file. You can export as GLB (glTF), which keeps the model and its materials bundled in a single file, or as OBJ, which is a long-standing format that almost every 3D program understands.

Both formats open directly in Blender, so you can inspect the model, retopologize it, retexture it, print it, or use it as a reference for your own work. No programming, no command line, no technical setup.

✨ Key Features

  • Live 3D preview - see every model the page has loaded before you save anything, so you know exactly what you are getting.
  • Click to pick an object - point at the model you want and select it. No guessing which file belongs to which mesh.
  • GLB (glTF) export - the modern format that keeps geometry, materials and textures together in one tidy file.
  • OBJ export - the universal fallback that works with Blender, Maya, 3ds Max, Cinema 4D and many more.
  • Texture capture - image files used by the model come along with it, so your export is not a grey blob.
  • Works across engines - three.js, Babylon.js, PlayCanvas and Unity WebGL scenes are all supported.
  • Runs right in your browser - available as a Chrome extension and a Firefox add-on.

🎯 How to Rip a 3D Model

  1. Open the website that contains the 3D content. Give the page a few seconds to load fully so its models appear on screen.
  2. Click the WebGLRipper icon in your browser toolbar. The extension panel opens with a live preview of every model it can see on that page.
  3. Look through the preview. Rotate and inspect the objects to confirm which one you want to keep.
  4. Click the object you want to capture. Click-to-pick selection highlights the model so you can be sure you have the right one.
  5. Choose your format. Pick GLB if you want a single self-contained file with textures included. Pick OBJ if you need maximum compatibility with older software.
  6. Save the file to a folder you can find again, such as your Downloads folder or Desktop.
  7. Open the file in Blender. Use File > Import and choose glTF (.glb) or Wavefront (.obj) depending on what you saved. The model and its textures load straight into your scene.

💡 Why People Use It

3D content on the web is displayed as pixels. There is no obvious "save" button, and the underlying model data is usually buried inside the page's code. WebGLRipper flips that around by showing you what is actually there and letting you take a copy.

Common uses include recovering a model you authored yourself but no longer have the original file for, gathering reference material for a Blender project, studying how a particular object was built, and archiving 3D assets before a site changes or shuts down.

Everything happens locally in your browser. Exported files go straight to your own computer's Downloads folder.

🛠️ Common Questions

The extension shows no models on a page

Reload the page and let it sit for several seconds before opening the extension. Some sites build their 3D scene only after the loading screen finishes, so opening the panel too early can catch an empty scene.

The model imports into Blender but looks flat grey

That usually means the textures did not come across with the geometry. GLB is the safer choice because it keeps the model and its images in one file. Re-export as GLB and import that instead of the OBJ.

The model appears too small or too large

Some websites scale their scenes to fit the browser window. In Blender, select the imported object and use the scale tool, or press Numpad-period to frame it in the viewport.

Nothing happens when I click an object

Try rotating the preview slightly first. Some scenes overlap several objects in the same spot, and picking works best when the object you want is facing you clearly.
